Access & Credentials

We only touch what
you authorize.

Some work requires access to your systems. When you submit a request that needs it, you'll provide credentials directly in your secure portal. We only use them for the specific task requested — nothing else, ever.

Break Glass Access
Temporary credentials created for one project. You create them, we use them, you revoke when done. Best for one-time work.
Compass Account
A dedicated Compass login (e.g. compass@yourbusiness.com) with scoped permissions. Persists as long as you're a client. Easiest for ongoing work.
Read-Only Access
When we only need to pull data — reports, exports, analysis. Minimum permissions required, nothing changed in your system.
Scoped Edit Access
Edit permissions limited to the specific area needed — one folder, one spreadsheet, one page. Not blanket admin access.
Authorization Policy All credentials are used solely to complete the specific work requested. Any additional access — even adjacent tasks — requires a separate written request. Credentials are stored securely and never shared. You'll receive a revocation reminder when every project closes.
A note on our process Compass Business Solutions may utilize technology tools — including AI-assisted software — to help analyze, draft, or produce work more efficiently. All work is reviewed before delivery. You receive work that has been checked for accuracy, quality, and relevance to your specific request. We will never deliver AI-generated content that has not been reviewed for accuracy, quality, and relevance to your specific request.
